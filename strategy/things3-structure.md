# Things 3 structure

The single map for how Alex's Things 3 is organized. Claude Code and Codex both read this before adding or moving anything, so the two agents file tasks the same way.

## Rules for agents

1. Read this file first. Never invent a new Area. Ask Alex before adding one.
2. Add to-dos to an existing Project. If none fits, add to the Area and flag it in the report.
3. Never delete or complete a to-do Alex created. Move, tag, or schedule only, and only when asked.
4. Every to-do starts with a verb and names one next action. "Call Miami broker", not "Acquisitions".
5. Deadlines only when a real date exists. Use When (Today, This Evening, Someday) for everything else.
6. Report every change in a list: what moved, from where, to where.
